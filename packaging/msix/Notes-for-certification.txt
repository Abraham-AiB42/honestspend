HonestSpend — notes for Microsoft Store certification (MSIX)

RESTRICTED CAPABILITY: runFullTrust
------------------------------------
HonestSpend is a local-first personal finance desktop app (WinUI 3) that:
  • Spawns a local Python fiscal engine (localhost API on 127.0.0.1 only)
  • Stores all ledger data on the user's machine (default %USERPROFILE%\.financial-os)
  • Optionally registers tray / logon helpers and scheduled backup tasks

No bank website passwords are collected. Money-in is CSV/OFX/PDF import and optional
BYOK Plaid (user's own API keys). Full trust is required to run the bundled engine
process and write user-chosen data directories outside the package install folder.

INTERNET
--------
internetClient: optional BYOK Plaid and optional Grok categorize (user keys only).
Core path works offline after first-run engine extract.

TEST ACCOUNT / FIRST LAUNCH
---------------------------
No account required. Launch app → main window appears immediately → Get started
(~2 min) or open Home. Engine extracts from engine-portable.zip to
%LocalAppData%\HonestSpend\engine on first EnsureRunning (may take 30–90s on slow disks).
UI remains interactive if the engine is still starting (Settings can retry).

ON-DEVICE TILES (policy 10.1.1.11)
---------------------------------
Package tiles are original HonestSpend brand art (ledger mark + product name on wide tile).
They do not use Visual Studio template assets, third-party product imagery, or Windows
stock icons. Solid brand background #0F2744; DisplayName/ShortName "HonestSpend".

VERSION
-------
Keep Package.appxmanifest Identity Version in sync with financial_os / ApplicationVersion
(e.g. 1.0.55.0). Identity Name/Publisher must match Partner Center Product identity.
Device family: Windows.Desktop only — uncheck Xbox and other families in the submission.
